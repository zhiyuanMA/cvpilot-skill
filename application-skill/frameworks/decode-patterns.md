# Decode Patterns — Recruiting-Speak Translation + Hidden Signal Dictionary

Two uses: (1) in Stage 1, translate marketing language into real requirements; (2) infer what kind of person the hiring manager is actually looking for from JD word choice.

---

## 1. Marketing Language → Real Requirement

Job postings almost never say what they mean directly. Common phrases and their real meaning:

| JD says | Real meaning |
|---|---|
| "strong experience with X" | Done X once or twice and can speak to it clearly — not a multi-year X expert |
| "deep expertise in X" | Genuinely wants 5+ years of X, verifiable via reference check |
| "passion for X" | No hard experience requirement, but you need to speak genuinely about interest in X |
| "working knowledge of X" | Heard of it, can discuss it — not required to have done it |
| "exposure to X" | Fully optional nice-to-have |
| "you've shipped …" (names specific artifacts) | Must have a showable portfolio / case study |
| "thrive in a fast-paced environment" | Fast pace, frequent direction changes, possible overtime |
| "comfortable with ambiguity" | No one will hand you a spec — you define the problem yourself |
| "wear many hats" | Understaffed, blurry role boundaries, likely an early-stage team |
| "self-starter / self-directed" | No micromanagement — you have to push things forward yourself |
| "collaborate cross-functionally" | High coordination/political cost, significant communication overhead |
| "data-driven" | Decisions need data backing — intuition alone won't fly |
| "user-obsessed / customer-obsessed" | User needs outrank internal stakeholder preferences in decisions |
| "high bar / craft / pixel-perfect" | Strict review process, multiple iteration rounds, portfolio scrutinized closely |
| "scale" / "scaled X to Y" | Needs prior experience with large-scale products / large user bases |
| "0 to 1" | No existing framework — exploratory, undefined-problem stage |
| "1 to N" / "scaling stage" | Product has PMF; the job is growth and maturation |
| "transform" / "modernize" | Legacy system, transformation-heavy work |
| "thought leadership" | Expected to speak/write publicly on behalf of the company |
| "mentor / coach others" | At minimum senior level, has led or grown other people before |
| "player-coach" | Both individual-contributor work and people leadership — roughly 1.5x workload |

## 2. Hidden Signal Dictionary (the most valuable part)

When these words/phrases recur in a JD, they reveal the hiring manager's preferred profile for the role.

### Self-driven vs. execution-oriented

| Word / phrase | Inference |
|---|---|
| ambiguity / unstructured / no playbook / undefined | Looking for a **self-driven** person who can define the problem without clear requirements |
| ownership / accountable / drive / end-to-end | Expects **full accountability end-to-end**, not just a piece of the work |
| comfortable wearing many hats | **Role boundaries are blurry** — expect work outside the formal job description |
| structured / process / framework / established | Looking for an **execution-oriented** person who follows an existing process |

### Collaboration density

| Word / phrase | Inference |
|---|---|
| influence / align / partner / persuade | **High political density** — cross-team collaboration and persuasion matter a lot |
| stakeholder management / cross-functional | **Complex reporting relationships** — managing up, down, and across |
| autonomous / independent work | **Mostly individual contribution**, low-meeting culture |
| highly collaborative team | **Meeting-heavy**, consensus-driven decision culture |

### Pace and pressure

| Word / phrase | Inference |
|---|---|
| fast-paced / move quickly / ship fast / scrappy | **Fast pace**, possible overtime, likely early-stage |
| iterate quickly / fail fast | **Trial-and-error culture** — mistakes are tolerated but must be corrected quickly |
| high bar / high standards / craft / quality | **High expectations** — multiple rounds of review and polish |
| thoughtful / deliberate / measured | **Slower pace**, decision quality prioritized over speed |

### Cultural leanings

| Word / phrase | Inference |
|---|---|
| mission-driven / impact / change the world | **Strong sense of mission** — possibly below-market pay, culture fit will be tested |
| inclusive / diverse / belonging | **DEI is emphasized** — expect related interview questions |
| ego-less / humble / no-asshole | **Past collaboration issues** — soft skills will be scrutinized closely |
| bold / opinionated / strong POV | **Expected to push a point of view** — people without one won't survive the process |
| customer-obsessed / user first | **User needs override internal stakeholder preference** in decisions |
| metrics-driven / data-informed | **Decisions need backing** — "I think" isn't sufficient justification |

### Team-stage signals

| Word / phrase | Inference |
|---|---|
| build the team / founding member / first X hire | **Early stage / 0-to-1** — you'll need to set everything up yourself |
| scale / grow / expand the team | **Expansion stage / 1-to-N** — a playbook exists but needs replicating |
| mature / established / optimize | **Mature stage** — focus is maintenance and optimization |
| transform / rebuild / modernize | **Transformation stage** — legacy systems, heavy rebuild workload |

### Level / title signals (what the real level is)

| JD implies | Actual level inference |
|---|---|
| "manage other designers/engineers" / "team of N" | Manager / Lead or above |
| "set vision / strategy" | Principal / Director |
| "execute against roadmap" | IC, likely mid-to-senior |
| "ship features" with no mention of vision | Mostly IC mid-level |
| "thought partner to CEO/CPO" | Principal / Lead |
| "first X hire" | Looks like an IC role but actually expects Lead-level output |

## 3. Reverse Reading (Red Flags)

Watch for these phrases — they can be covering something up:

| JD says | What to watch for |
|---|---|
| "wear many hats" + lists 5 distinct responsibilities | One person doing three people's jobs |
| "fast-paced" + "no work-life balance trade-off" mentioned defensively | Likely means the opposite — significant overtime |
| "we're like a family" | Blurry boundaries, overtime-normalizing culture |
| repeated "rockstar / ninja / 10x" | Unprofessional, immature culture |
| an extremely wide salary range (e.g. $80k–$250k) | Level is muddled — lowballing risk |
| 10+ Must-Haves listed | The hiring manager doesn't know exactly what they want — resume screening will be inconsistent |
| role has been open 6+ months | Internal disagreement on JD / level / salary — expect a bumpy interview process |
| "looking for someone who can do X + Y + Z" spanning very different disciplines | Trying to hire one person to save money on three — scope will fight itself after hire |
