# Competency Tags — Dictionary + Reverse Lookup

Reference framework for Stage 4 (`prompts/04-bq-prep.md`). Two uses: (1) tag what a CV experience demonstrates, (2) given a behavioral question, look up which competency it's really testing.

## Core competency tags

| Tag | What it tests | Typical question openers |
|---|---|---|
| **Ownership** | Taking initiative, seeing things through, being accountable for outcomes | "a time you went beyond your role" / "took initiative" |
| **Conflict Resolution** | Handling disagreement, repairing a relationship, reaching alignment | "a disagreement with a coworker/manager" |
| **Influence / Persuasion** | Moving something forward without formal authority, changing someone's mind | "influenced without authority" / "convinced someone" |
| **Stakeholder Management** | Coordinating and aligning across teams, upward, or with clients | "managed competing priorities across teams" |
| **Dealing with Ambiguity** | Making progress with incomplete information or no precedent | "a time things were unclear / no clear path" |
| **Leadership** | Leading people, setting direction, motivating others, stepping up informally | "led a team / project" / "motivated others" |
| **Growth Mindset / Learning** | Reflecting on and growing from feedback or failure | "biggest failure" / "received tough feedback" |
| **Drive for Results** | High standards, working under pressure, delivering despite obstacles | "a challenging goal" / "under a tight deadline" |
| **Data-Driven Decision** | Using data/evidence to make a judgment call | "a decision based on data" |
| **Customer Obsession** | Prioritizing the user/customer perspective in trade-offs | "went above and beyond for a customer" |
| **Innovation / Bias for Action** | Creative problem-solving, moving fast on incomplete information | "a creative solution" / "moved fast with incomplete info" |
| **Handling Failure / Resilience** | Recovering from a mistake or setback | "a mistake you made" / "missed a deadline" |

## Reverse lookup ("how do I answer this question")

1. Read the behavioral question and map it to 1–2 core competencies from the table above.
2. Check the CV for experience that clearly demonstrates those competencies — with real evidence, not a generic claim.
3. If multiple CV experiences fit, pick the one with the strongest signal (clearest quantified result, best alignment with the target company's style).
4. If nothing in the CV fits, flag it honestly as a gap — see Stage 4's gap list — rather than forcing a weak match.

## Tagging discipline

- Tag each story with **one primary competency plus one or two secondary ones** — don't over-tag (tagging everything defeats the point of tagging).
- Primary = the most unambiguous signal in the story; secondary = other angles the same story could be opened from.
- A failure/setback story almost always carries a secondary `Growth Mindset` tag — don't forget to add it.
